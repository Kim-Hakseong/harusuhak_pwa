# 고등 수학 확장 유형 HIG-15 ~ HIG-35 (1.0.2)

2022 개정 수학과 교육과정(교육부 고시 제2022-33호 [별책 8])에서 기존 HIG-01~14가 쓰지 않은 고등학교 성취기준 21개를 골라 유형을 추가했다.
모든 유형은 하(easy)·중(normal)·상(hard) 세 단계를 내고, 정답은 `verify/oracles/high.js`의 독립 oracle(지문·입력 변수만 읽고 다시 계산)로 검증한다. 새 유형에는 그림이 없다.

## 출처
- 성취기준 코드·문안: 2022 개정 수학과 교육과정 고시문의 나무위키 전사본(이전 감사 `CURRICULUM_AUDIT.md`와 같은 출처)
  - 공통수학1·2: https://namu.wiki/w/공통수학1 (공통수학1·공통수학2 성취기준 목록 포함)
  - 대수: https://namu.wiki/w/2022%20개정%20교육과정/수학과/고등학교/대수
  - 미적분Ⅰ: https://namu.wiki/w/2022%20개정%20교육과정/수학과/고등학교/미적분Ⅰ
  - 확률과 통계: https://namu.wiki/w/2022%20개정%20교육과정/수학과/고등학교/확률과%20통계
- 공통수학 영역 코드 체계(`[10공수1-01]`~`[10공수2-03]`)는 한국교육과정평가원 「최소 성취수준 보장 지도 자료(공통수학1, 2)」와 일치함을 이전 감사에서 확인했다.
- 기존 HIG-01~14가 쓰는 8개 코드(`[10공수1-01-02]`, `[10공수1-02-02]`, `[10공수1-02-03]`, `[10공수1-03-03]`, `[10공수2-01-01]`, `[10공수2-01-04]`, `[10공수2-02-06]`, `[12대수03-02]` 등)의 문안이 같은 전사본과 글자 단위로 일치해 전사본 신뢰도를 교차 확인했다.
- 원문 PDF(NCIC, ncic.go.kr)로 한 번 더 대조하는 것을 권장한다(이번 작업 환경에서는 원문 PDF를 직접 내려받지 않았음).
- 확률과 통계를 추가함에 따라 고등 수학 팩의 `targetGrade`를 '공통수학·대수·미적분Ⅰ·확률과 통계'로, `title`·`desc`를 35개 유형 기준으로 바꿨다.

## 기존 HIG-01 ~ 14의 난이도 분기
- 중(normal)은 기존 코드 그대로(난수 호출 순서·횟수·문구 불변, `node verify/snapshot-normal.js` → SNAPSHOT 동일).
- 하·상은 동결 oracle(`verify/verify-answers.js`)이 그대로 파싱할 수 있도록 지문 문형과 variablesInfo 키를 유지하고 수의 범위·계수·조건만 바꿨다.
  예: HIG-02 상은 x의 계수가 홀수라 D/4 대신 D를 쓰고 경계가 정수가 아님, HIG-04 상은 위로 볼록(계수 −1)이거나 꼭짓점이 구간 밖, HIG-11 상은 절댓값·두 변수 조건과 필요충분조건, HIG-12 상은 결과가 음수, HIG-13 상은 공비가 음수, HIG-14 상은 최고차항 계수가 −1(극대·극소 위치 반전) 또는 2.
- 그림이 있는 HIG-04·09·10·14는 세 단계 모두 같은 그림 스펙을 내며, 세 단계 모두에서 그림 라벨에 정답 숫자가 나오지 않음을 확인했다.
- 동결 oracle 문형 제약 때문에 HIG-03·07·10의 상은 '같은 문형에서 큰 수·음수'에 가깝다(문형 자체를 바꾸면 동결 검증기가 파싱하지 못함).
