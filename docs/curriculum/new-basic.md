# 기초 수학(basic) 확장 유형 — BAS-15 ~ BAS-35

- 대상: 2022 개정 수학과 교육과정 초등 5~6학년군. 성취기준 코드·문장은 교육과정 원문 그대로 옮겼다.

## 기존 14개(BAS-01~14) 난이도 방식

- 중(normal): 기존 코드를 한 글자도 바꾸지 않았다(rng 호출 순서 동일, `node verify/snapshot-normal.js` → SNAPSHOT 동일).
- 하·상: `if (tier === 'easy' || tier === 'hard') { … return }` 분기를 normal 코드 앞에 두었다. 지문 형식과 variablesInfo 키는 동결 oracle(verify/verify-answers.js)이 그대로 해석할 수 있게 유지했다.
