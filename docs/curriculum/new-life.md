# 생활 수학(life) 유형 확장 — LIF-15 ~ LIF-35 (1.0.2)

생활 수학 14개 → 35개. 새 21개는 2022 개정 수학과 교육과정의 진로 선택·융합 선택 과목
**경제 수학 `[12경수..]`, 직무 수학 `[12직수..]`, 실용 통계 `[12실통..]`** 성취기준에 연결했다.
기존 LIF-01~14와 개념이 겹치지 않게 골랐다(같은 코드를 쓰는 경우도 다룬 상황·계산이 다름).

## 출처
- 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정 — 공식 PDF 원문 대신, 이전 점검(`CURRICULUM_AUDIT.md`)과 같이 나무위키 고시문 전사본을 사용했다.
  기존 LIF 유형에 쓰던 코드·문안(`[12경수01-01]~[12경수01-04]`, `[12직수01-01]`, `[12직수01-03]`, `[12직수02-01]`, `[12직수02-02]`)이 전사본과 글자 단위로 일치함을 확인했다.
  - 경제 수학: https://namu.wiki/w/2022%20개정%20교육과정/수학과/고등학교/경제%20수학
  - 직무 수학: https://namu.wiki/w/2022%20개정%20교육과정/수학과/고등학교/직무%20수학
  - 실용 통계: https://namu.wiki/w/2022%20개정%20교육과정/수학과/고등학교/실용%20통계
- 2차 출처이므로 NCIC(https://ncic.go.kr) 원문으로 한 번 더 대조하기를 권장한다.

## 기존 14개(LIF-01~14) 난이도
- 중(normal)은 바이트 단위 그대로(`node verify/snapshot-normal.js` → SNAPSHOT 동일).
- 하·상은 동결 oracle(`verify/verify-answers.js`)이 그대로 파싱하도록 지문 문형과 variablesInfo 키를 유지하고 수의 범위·조건만 바꿨다.
  - 숫자 후보만 바꾼 유형(rng 호출 순서 동일): LIF-02·03·04·05·07·09
  - 별도 분기(중 코드는 손대지 않음): LIF-01·06·08·10·11·12·13·14
  - 예: LIF-06 상은 정기권 요금에 자투리를 더해 n > (소수) 경계를, LIF-08 상은 수수료 25~40원(지문의 "스프레드)가 X원" 형식 유지)을, LIF-14 상은 10·12개월 할부와 4.8·6% 예치 이자로 할부가 이기는 경우를 만든다.

## 검증
- 새 oracle: `verify/oracles/life.js` (지문·variablesInfo 입력만 읽음, 적금·연금·대출 이자는 공식 대신 직접 합산, 경우의 수·최적화·예산은 전수 조사)
- `node verify/verify-tiers.js --level life --rounds 100` → 35 유형 × 3 단계 FAIL 0 / AMBIG 0 / lint 0 / dupOptions 0
