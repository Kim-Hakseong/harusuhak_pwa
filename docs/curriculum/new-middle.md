# 중등 수학 확장 유형 (MID-15 ~ MID-35) — 2022 개정 성취기준 대조

1.0.2 확장: 중등 수학 14개 → 35개(5주 × 7요일). 새 21개 유형은 기존 MID-01~14가 쓰지 않은 2022 개정 중학교 성취기준을 4개 영역·3개 학년에 고루 배치했다. 모든 유형은 하(easy)·중(normal)·상(hard) 3단계를 내고, 그림은 쓰지 않는다.
