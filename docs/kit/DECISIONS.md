## D-018 난이도 하·중·상 + 유형 140개 (2026-11-06, 사용자 요청)
- 문제 카드 메타 줄 오른쪽에 [하|중|상] 버튼(시안 B, 사용자 선택). 1행 [성취기준 코드 · 하중상], 2행 [단원]으로 고정. 배지·태그는 한 줄(nowrap).
- `generateProblem({ tier })`. 중(normal)은 기존 시드·코드 경로 그대로 → 오늘의 문제·학습 기록·동결 검증기 결과 불변(`verify/snapshot-normal.js` 로 56개 × 100 바이트 비교).
- 수준마다 14 → 35개(5주 × 7요일 순환이 딱 맞는 수). 사용자에게 제안한 120개 대신 140개 — 30개면 5주차에 5개가 반복되기 때문.
- 문항 수학 로직 동결(CLAUDE.md)의 예외는 사용자 명시 요청에 따름. 동결 검증기는 그대로 두고, 그 oracle 구간을 읽어 쓰는 `verify/verify-tiers.js` + 새 유형 oracle(`verify/oracles/<level>.js`, verifier-first)로 140개 × 3단계를 검사.
- 오늘의 공식 기록은 그날 처음 푼 난이도로 1회. 다른 난이도로 다시 풀면 추가 연습으로 센다.
