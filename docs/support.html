자주 묻는 질문

회원가입이나 인터넷 연결이 필요한가요?

아니요. 모든 문제는 기기 안에서 만들어지고, 학습 기록도 기기에만 저장됩니다.

매일 알림이 오지 않아요.

설정 탭 → 매일 알림을 켜고 시간을 고르세요. 그래도 오지 않으면 iPhone 설정 앱 → 하루수학 → 알림에서 알림 허용이 켜져 있는지 확인해 주세요.

휴대폰을 바꾸면 학습 기록은 어떻게 되나요?

설정 탭 → 학습 기록 JSON 백업으로 파일을 내보내 보관할 수 있어요. 앱을 삭제하면 기기에 저장된 기록도 함께 삭제됩니다.

개인정보는 어떻게 처리되나요?

어떤 개인정보도 수집하지 않습니다. 개인정보 처리방침을 참고해 주세요.
